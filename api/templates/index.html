Research Agent API

Une API pour rechercher, extraire et compiler des informations sur un thème donné

À propos

Cette API expose les fonctionnalités du Research Agent, un agent intelligent basé sur Pocket Flow qui recherche, extrait et compile des informations sur un thème donné en utilisant Gemini 2.5 Flash.

L'agent effectue les opérations suivantes :

  • Génération de requêtes optimisées avec Gemini
  • Recherche web via SerpAPI
  • Extraction de contenu avec Selenium
  • Compilation en Markdown structuré

Endpoints disponibles

  • POST /research/

    Lance une nouvelle recherche basée sur le thème fourni

  • GET /research/{research_id}/status

    Vérifie le statut d'une recherche en cours

  • GET /research/{research_id}/results

    Récupère les résultats d'une recherche terminée

  • GET /research/

    Liste toutes les recherches avec leur statut
